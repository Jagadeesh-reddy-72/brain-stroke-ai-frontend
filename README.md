# 🧠 NeuroView AI · Stroke Detection

A modern web interface for analyzing Diffusion MRI (DWI) images using an AI-powered stroke detection backend.

---

## 🚀 Features

- 📁 Upload MRI images (image format)
- 🖼️ Instant image preview with metadata
- 🔬 AI-based stroke prediction
- 📊 Confidence score visualization
- ⚡ Clean and responsive UI
- 🌐 Backend API integration (Hugging Face)

---

## 🛠️ Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend API: Hugging Face Space
- Styling: Custom CSS (Glassmorphism UI)

## ⚙️ How It Works

1. User uploads an MRI image
2. Image preview is shown instantly
3. Click "Analyze"
4. Image is sent to backend API
5. AI returns:
   - Prediction (Stroke / No Stroke)
   - Confidence score
6. Result is displayed visually

---

## 🔗 Backend API

https://jagadeesh72-stroke-predict.hf.space/predict

- Accepts image input
- Returns JSON response:
  - prediction
  - confidence
